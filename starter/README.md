# Starter Ch02 — Refactoring EduHub với SOLID và Design Patterns

Bài tập Ch02 refactor EduHub theo SOLID và Design Patterns.

## Việc cần làm

Phân tích các vi phạm ban đầu nằm trong [`docs/solid-analysis.md`](../docs/solid-analysis.md). Bản refactor tách service và repository, đồng thời minh họa Factory, Decorator, Strategy và Observer.

## Lệnh

```bash
dotnet build Ch02.Refactor.sln
dotnet test Ch02.Refactor.sln
dotnet run --project Ch02.Refactor
```

Unit test domain dùng mẫu Arrange-Act-Assert.
